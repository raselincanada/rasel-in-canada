RASEL IN CANADA — FREE NETLIFY EDITOR SETUP

WHAT YOU GET
- Free same public website and custom domain.
- Free Netlify hosting (within Netlify's free usage allowance).
- Private editor at https://raselincanada.ca/admin/
- Editable homepage, About text, contact details, social links, stories, albums, photos, videos, and Canada guides.

ACCOUNTS NEEDED
1. A free GitHub account.
2. A free Netlify account.

IMPORTANT: CONNECT THE REPOSITORY
1. Create a GitHub repository named: rasel-in-canada
2. Upload every file and folder from this package to the repository.
3. The editor is already configured for GitHub user Raselincanada.
4. In Netlify, choose Add new project > Import an existing project > GitHub.
5. Select the rasel-in-canada repository. Netlify will read netlify.toml automatically.
6. Deploy the project.

ENABLE THE EDITOR LOGIN
The package uses Decap CMS with the GitHub backend. In Netlify, configure GitHub as an authentication provider for the project. Your GitHub account must have write access to the repository.

CONNECT YOUR DOMAIN
After the Netlify preview works, add raselincanada.ca under Domain management. Follow Netlify's displayed DNS instructions at the company where the domain is registered.

EDIT YOUR WEBSITE
Visit https://raselincanada.ca/admin/ and sign in with GitHub. Select Website Settings, Stories & Albums, or Canada Guides. Publishing creates a GitHub update and Netlify automatically rebuilds the public site.

SECURITY
Keep the GitHub repository private if your free GitHub plan allows it. Never place passwords or secret keys inside the repository.
